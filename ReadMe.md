# Minecraft Wood Cutting

## 前言：
作者写这个数据包的起因是因为合成矿车时不能直接放漏斗合成漏斗矿车，所以就写了这个数据包。

## 切石机：
西瓜=西瓜  
南瓜=雕南瓜  
雪块=八个雪片  
铜制方块=去蜡去锈  
各种原木=各种木材  
\
工作台：\
投掷器+弓=发射器  
合成投掷器中间放弓=发射器  
合成矿车时在中间放对应的东西=对应的矿车
